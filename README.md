📖 Project Description (GitHub README)
🧾 Overview

This project is an end-to-end Business Intelligence solution built using SQL Server and Power BI to analyze retail sales, customer behavior, product performance, and supply chain efficiency.

It transforms raw transactional data into interactive dashboards and actionable business insights using advanced SQL queries, Power Query ETL processes, and DAX measures.

🎯 Business Objective

The goal of this project is to help a global retail company:

Improve sales performance tracking
Understand customer purchasing behavior
Optimize product profitability
Analyze supply chain efficiency
Detect high-return or abnormal transactions
Forecast future sales trends
Support data-driven decision-making
